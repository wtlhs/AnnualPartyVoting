🔧 清除浏览器缓存

注意：如果你看到HTTPS相关错误，请按照以下步骤清除浏览器缓存。

方法一：快捷键清除（推荐）

1. 按 Ctrl + Shift + Delete (Windows) 或 Cmd + Shift + Delete (Mac)

2. 选择"全部时间"

3. 勾选"缓存的图片和文件"和"Cookie及其他网站数据"

4. 点击"清除数据"

方法二：使用隐身模式

1. 按 Ctrl + Shift + N (Chrome) 或 Ctrl + Shift + P (Firefox)

2. 在隐身窗口中访问系统

方法三：强制刷新

1. 按 Ctrl + F5 或 Shift + F5

2. 或者按住 Shift 键点击刷新按钮

方法四：清除特定域名缓存

Chrome浏览器：

1. 地址栏输入：chrome://settings/content/all

2. 搜索你的IP地址（如：172.18.0.250）

3. 点击删除按钮
