修复投票页面导航问题

🔍 问题诊断

投票确认页面中的"返回首页"按钮无法正常工作，可能的原因包括：

  • JavaScript事件监听器干扰了正常导航
  • popstate事件处理器过于激进
  • CSS样式阻止了点击事件
  • 服务器路由配置问题

✅ 已实施的修复

已修复了 vote.js 中的 popstate 事件处理器，避免干扰正常导航：

// 修复前（有问题的代码）: window.addEventListener('popstate', function(event) { initializeVotePage(); // 这会干扰所有导航 }); // 修复后（改进的代码）: window.addEventListener('popstate', function(event) { const currentPath = window.location.pathname; if (currentPath.startsWith('/vote/')) { initializeVotePage(); // 只在投票页面内重新初始化 } });

🔧 额外的修复建议

如果问题仍然存在，可以尝试以下解决方案：

1. 强制导航函数

function forceNavigateHome() { // 移除所有可能的事件监听器 window.removeEventListener('popstate', arguments.callee); window.removeEventListener('beforeunload', arguments.callee); // 强制导航到首页 window.location.href = '/'; }

2. 使用 window.location.replace

// 替换当前页面历史记录，避免返回按钮问题 function replaceWithHome() { window.location.replace('/'); }

3. 延迟导航

// 给页面一点时间完成当前操作 function delayedNavigateHome() { setTimeout(() => { window.location.href = '/'; }, 100); }

  • 投票页面可以正常加载
  • 返回首页链接可以点击
  • JavaScript导航正常工作
