测试隐藏直接访问标识功能

功能说明

投票确认页面现在会根据访问来源显示不同的标识：

  • 📱 扫码投票：从扫码页面(/scan)访问时显示
  • 👥 按姓名投票：从用户列表页面(/user-list)访问时显示
  • 🔗 直接访问：直接访问时隐藏

测试不同访问方式

点击下面的按钮测试不同的访问方式和标识显示：

预期行为

访问方式 来源页面 显示标识 是否显示
扫码投票 /scan 📱 扫码投票 ✓ 显示
按姓名投票 /user-list 👥 按姓名投票 ✓ 显示
直接访问 其他/直接输入URL 🔗 直接访问 ✗ 隐藏

技术实现

通过检查 document.referrer 来判断访问来源：

if (referrer.includes('/scan')) {
    // 显示扫码投票标识
} else if (referrer.includes('/user-list')) {
    // 显示按姓名投票标识
} else {
    // 隐藏直接访问标识
    voteSource.style.display = 'none';
}
