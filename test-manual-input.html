📝 功能说明

主要投票流程（扫码）：

  1. 访问扫码页面 - 点击"扫码投票"按钮
  2. 启动摄像头 - 点击"开始扫描"按钮
  3. 扫描二维码 - 将摄像头对准参与者的二维码
  4. 自动验证 - 系统自动验证二维码并跳转投票页面

备选投票流程（手动输入）：

  1. 显示手动输入 - 点击"手动输入ID"按钮
  2. 输入6位数字ID - 在输入框中输入参与者的6位数字ID
  3. 确认投票 - 点击"确认投票"按钮或按回车键
  4. 验证跳转 - 系统验证ID并跳转投票页面

智能降级机制：

  • 🎥 摄像头可用时：优先显示扫码功能
  • 📱 摄像头不可用时：自动显示手动输入选项
  • 🔄 用户可以在两种方式之间自由切换
